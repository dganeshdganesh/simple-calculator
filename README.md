# Ganesh Calculator

A simple calculator project with:

- Frontend: HTML, CSS, and JavaScript
- Backend: Flask Python app

## Structure

- backend/app.py
- backend/requirements.txt
- frontend/index.html
- frontend/style.css
- frontend/script.js

## Run

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend
Open frontend/index.html in your browser.
